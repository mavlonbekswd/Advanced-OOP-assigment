# 1. Introduction

*Target: 120 words. Status: complete, subject to revision once the application is finished.*

---

This report describes the planning, design, implementation and testing of a
single-player Battleship game written in Java for module MOD004883. The player
fires at a grid hiding a computer-placed fleet of six ships. The standard game
is ten squares by ten and ends when every ship is sunk; a difficulty setting
varies the grid and limits the shots allowed, so a game can also be lost.

The report follows the order in which the work was carried out: the requirements
taken from the assessment brief, the plan written before any code existed, the
design decisions and how they were put into practice, the testing used to show
the rules behave correctly, and an evaluation of the finished application
against the original requirements.

## O'zbekcha (tekshirish uchun — hisobotga kirmaydi)

Bu hisobot MOD004883 moduli uchun Java tilida yozilgan bir o'yinchili Battleship
o'yinining rejalashtirilishi, dizayni, amalga oshirilishi va testlanishini tasvirlaydi.
O'yinda odam o'yinchi 10x10 to'rga o't ochadi; to'rda kompyuter joylashtirgan olti
kemadan iborat flot yashiringan, va hamma kema cho'kkanda o'yin tugaydi.

Hisobot ish qanday tartibda bajarilgan bo'lsa, shu tartibda tuzilgan. U topshiriq
briefidan olingan talablar va kod yozilishidan oldin tayyorlangan rejadan boshlanadi,
keyin asosiy dizayn qarorlari va ular qanday amalga oshirilgani tushuntiriladi.
So'ngra qoidalar to'g'ri ishlashini ko'rsatish uchun qilingan testlar keltiriladi, va
oxirida tayyor ilova dastlabki talablarga nisbatan baholanadi.
