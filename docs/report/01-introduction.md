# 1. Introduction

*Target: 120 words. Status: complete, subject to revision once the application is finished.*

---

This report describes the planning, design, implementation and testing of a
single-player Battleship game written in Java for module MOD004883. In the game, a
human player fires at a ten by ten grid that hides a computer-placed fleet of six
ships, and the game ends when every ship has been sunk.

The report is organised to follow the order in which the work was carried out. It
begins with the requirements taken from the assessment brief and the plan that was
written before any code existed, then explains the main design decisions and how they
were put into practice. It then presents the testing that was used to show the rules
behave correctly, and finishes by evaluating the finished application against the
original requirements.

o'yinining rejalashtirilishi, dizayni, amalga oshirilishi va testlanishini tasvirlaydi.

briefidan olingan talablar va kod yozilishidan oldin tayyorlangan rejadan boshlanadi,
keyin asosiy dizayn qarorlari va ular qanday amalga oshirilgani tushuntiriladi.

oxirida tayyor ilova dastlabki talablarga nisbatan baholanadi.
