# 8. Conclusion

*Target: 80 words. Status: complete.*

---

This project produced a working single-player Battleship game that meets every
requirement in the brief, together with three of the extensions it lists: random
placement, a mouse-controlled interface and difficulty levels. Separating the rules
from the interface allowed the game to be tested thoroughly before anything was
drawn, and made the last of those extensions cheap enough to add after the rest was
finished. Writing checks before code found two defects that would otherwise have
reached the finished application.
The single most valuable next step would be to convert those checks to JUnit.
