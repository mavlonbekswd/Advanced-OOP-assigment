Figures A, B and C describe the design **as it was planned**, which is what the
planning section of the report requires. They deliberately do not match the finished
code; the differences are listed in report section 4.4. Figure D is the final model,
taken from the code as it now stands.

Two earlier documents were created by importing Mermaid source. Lucid stores that as
a code block rather than as shapes, so it cannot be exported as an image. They were
replaced by the documents above and can be deleted:
`142dec6e-4743-4e0a-a070-91e6f7433d45` and `b67e4558-3b55-401c-b990-f2772944e991`.
